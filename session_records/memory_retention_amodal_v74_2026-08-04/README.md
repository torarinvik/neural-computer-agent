# v74 three-slot / two-row retention rung — superseded harness record

v74 was the first attempt to generalize the outcome-only retention harness from
two slots and one memory row to three opaque slots and two bounded memory rows.
The event window was expanded to four so the target cue remained available
through all three probe events.

This record is retained for provenance but is superseded. Its balanced-order
counterfactual arms duplicated verifier rows without duplicating the trainer's
balanced target-position assignment, so the paired intervention could compare
different hidden target positions. The resulting position-specific metrics are
confounded and must not be treated as decisive evidence.

The original protected 1,024/1,024 seed-17 values are preserved in `seed_17.json`
and in the ledger, but they are historical diagnostics only. The corrected
replication is recorded under
`session_records/memory_retention_amodal_v76_2026-08-04/`.

The compact accounting record is `seed_17.json`.
