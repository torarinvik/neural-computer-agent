# v75 cross-adapter memory retrieval qualification

v75 qualifies a narrow cross-adapter memory result with three seeds. A writer
adapter stores two opaque outcome rows; a frozen-controller reader adapter is
trained from paired unlabeled event consistency across a fixed trace-zero
latent rotation, then verified with scalar outcome recall.

The four-population fresh-token audit is the primary gate. Aligned reader
minimum recall is `0.9336`, `0.9941`, and `0.9990` for seeds 17, 18, and 19.
Aligned-minus-raw reader gain is positive for every population pair, with
mean gains `0.1694`, `0.3066`, and `0.3135`. Swapped-slot maxima are `0.5781`,
`0.5029`, and `0.5234`; clear and corruption remain near chance.

This promotes only the replaceable-neural-IR cross-adapter retrieval
boundary. It does not promote natural-modality semantics, arbitrary raw
frontend alignment, persistent episodic utility, or multi-row learned
retention under three-way interference. The latter remains rejected in v74.

The compact per-seed accounting records and sample-efficiency ledger are in
this directory.
