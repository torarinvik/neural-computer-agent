This is the next scaling rung after two-source shared consolidation. Three
protected external files were replaced by one shared routed stack. The
inherited student started from source 0 and learned all three source
procedures from fresh outcomes; a fresh student received the same budget. A
unique stable-prefix winner was accepted directly. Tied stable-prefix results
would still require the strict maximin behavior margin before inherited weights
could survive.

1. `reverse -> adjacent_xor -> complement -> prefix_parity`
2. `global_parity -> reverse -> adjacent_xor -> rotate`
