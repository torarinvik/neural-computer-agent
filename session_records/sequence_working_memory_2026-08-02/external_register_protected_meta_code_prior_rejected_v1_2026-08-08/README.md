# Protected operator-family and code prior — rejected

`factorized_protected_meta` adds a zero-initialized, code-conditioned residual
family while the mastered base operator remains frozen. The source
primitives remain retained on both seeds. New `rotate` acquisition does not
show positive transfer: random-code initialization ties or loses to fresh,
and mean initialization from the four mastered instruction vectors gives
`8,192/8,192` bits on seed `69316` and `12,288/4,096` on seed `69317`.

All mastery, retention, shuffled-null, missing-evidence, reload, corruption,
frozen-parent, and zero-replay gates pass. The intervention is rejected as a
new-primitive transfer mechanism. The system needs an explicit expandable
computation basis rather than another fixed code-conditioned residual.
