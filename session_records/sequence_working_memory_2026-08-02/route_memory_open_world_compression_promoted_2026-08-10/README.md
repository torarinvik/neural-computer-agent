# Promoted: open-world redundancy discovery and compression

The persistent store began with mastered anchors and one distractor—zero
duplicate pairs were seeded. Across 50 latent lifetimes, each route was
introduced once and then presented again with controlled noise. The planner
had to preserve both observations, discover their redundancy from generic
relations, and commit verifier-gated consolidation before advancing.

Across seeds `86001`–`86004`, all 50 latent lifetimes completed and all 50
were compressed. Trained runs used 262–691 online verifier updates, while
fresh controls completed zero or one lifetime. Sampled-prefix and full-final
retention were `1.0` in every seed, including after coordinate reversal. The
controller was frozen and replay was zero. A generic key-similarity prior was
used only to make newly discovered pair exploration tractable; the policy
still learned action/selector decisions from verifier utility.

This promotes bounded open-world redundancy discovery and compression. It does
not establish arbitrary semantic equivalence, unrestricted growth, universal
continual learning, or autonomous verifier design.
