# Three-generation page router with source-only normalization

Promoted replicated pressure test of repeated opaque external growth. Thirty
source candidates remain in three normalized pages; three independent append
generations add 18 candidates each in nine pages, for 84 candidates and 30
pages total. The frozen signature normalizer is fit only on the original
source keys. Each generation has an independent token-preserving router and
the verifier-gated cascade is source → generation 1 → generation 2 →
generation 3.

Seeds 69316 and 69317 pass all strict gates: candidate and page mastery,
per-target/per-page floors, permutation, generation-local reward-shuffled
nulls, source immutability, controller invariance, no unresolved rows, exact
reload, and zero replayed examples. Per seed: 21,376 optimizer updates,
2,214,912 unique verifier bits, and 2,214,528 unique logical lifetimes.

The mean fresh-attempt count is 2.2857 and the fallback rate is 0.6429. This
confirms that capability retention scales, while routing and verifier work
still grow linearly with the number of external generations. The result is
bounded repeated external growth, not unrestricted memory growth,
consolidation/compression, arbitrary new computation, or general continual
learning.
