# Goal-conditioned external relevance — promoted

This two-seed audit repeats the matched-telemetry ambiguity control, but adds
an opaque learned-space query aligned with the capability needed by the
current goal. The external lifetime transaction combines query/key cosine
alignment with generic lifetime telemetry before proposing a stable logical
eviction address.

Both seeds achieved `1.000` held-out query-conditioned selection against the
matched-telemetry random reference of `0.500`. Retained factual transition
models still passed held-out verifier probes, policy persistence was exact,
and controller updates and replayed transition examples were zero.

This promotes the external query-conditioned retrieval boundary, not the
learning of the query itself. The query is treated as a learned opaque output
from the replaceable controller/event system; the existing outcome-only
cross-token relevance experiments cover that upstream learning problem. The
result is not general continual learning or unrestricted memory growth.
