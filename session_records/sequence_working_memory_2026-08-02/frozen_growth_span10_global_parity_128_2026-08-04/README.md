# Rejected orthogonal global-aggregation acquisition

The verifier-private `global_parity` primitive asks the controller to emit the
parity of the entire retained span at every query position. It is
orthogonal to complement-based artifacts and the frozen parent scored only
about 2% in a direct saturation probe.

At the sub-minute 128-update rung, frozen external growth produced effectively
zero target gain and zeroed-growth ablation was not causal. The experiment was
therefore rejected and not promoted to a longer run. Global aggregation and
its credit-assignment path remain open.
