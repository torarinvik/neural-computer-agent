# Factored unresolved-evidence quarantine

This archive records the five-seed quarantine continuation of the partial
stream acquisition rung. Four unresolved one-row bundles from contradictory
partial evidence were stored in a bounded external quarantine, persisted and
reloaded, inspected without mutation, and released with their bundle
boundaries intact. No quarantine row was combined with another regime and no
quarantine row trained or promoted a model.

All earlier partial-stream acquisition, retention, routing, frozen-core, and
read-only contradiction gates also passed. This promotes bounded unresolved
evidence retention and recovery; it does not provide a learned policy for
automatically resolving, merging, or promoting quarantined evidence.
