# No-replay generated composition curriculum pilot (2026-08-06)

Status: rejected; no weights or artifact promoted.

The routed external capability stack was trained through six sequential
phases. Each phase exposed only fresh verifier outcomes for one newly admitted
two-primitive composition; earlier generated-composition examples were not
replayed. After the final phase, retention ranged from `0.3281` to `0.7188`,
and no phase reached a stable `0.75` prefix.

The frozen parent stayed unchanged and the accounting recorded zero replayed
examples. This rejects the tested short curriculum budget as sufficient for
continual compositional expansion. The next rung must first establish stable
single-composition acquisition and then expand with a larger fresh budget or a
more explicit external write/lookup mechanism.
