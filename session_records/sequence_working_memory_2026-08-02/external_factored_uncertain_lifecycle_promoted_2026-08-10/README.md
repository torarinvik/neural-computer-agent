# Reliability, delayed evidence, and factored lifecycle

This three-seed pressure test combines the external factual router, replay-free
reliability statistics, and replay-free wait/absence statistics. A low-error
corruption is vetoed and retained in quarantine; clean reversals still route
with the reliability gate active. Delayed partial evidence is retained and
resolved once, while fast absence releases without mutating factual memory.

At full capacity, a novel regime is refused. Retention-verified growth admits
it, then a middle slot is evicted and a fourth regime is promoted. Surviving
regimes remain routable, all external states restore exactly, and the base,
controller, and context encoder remain frozen.

This promotes a bounded uncertain-evidence lifecycle. It does not establish
unrestricted memory growth, multimodal grounding, arbitrary new computation,
or general continual learning.
