# Online nonlinear reliability gating with verified factored growth

This three-seed pressure test applies replay-free external reliability state to
the factored nonlinear residual router. A frozen source regime is promoted,
clean verifier outcomes warm the gate, and a low-error corrupted revisit is
vetoed and quarantined without staging a replacement candidate. A fresh
gate-disabled control accepts the same corruption.

A genuinely novel nonlinear regime still stages and promotes through the
copy-on-write residual path. Because the router is configured with one slot and
verified auto-growth, promotion grows capacity from one to two while retaining
the original source route. The base model, controller, and context encoder stay
frozen; no old evidence is replayed; router and external reliability state
restore exactly.

This promotes a bounded reliability-to-candidate-admission boundary. It does
not establish unrestricted memory growth, multimodal grounding, arbitrary new
computation, or general continual learning.
