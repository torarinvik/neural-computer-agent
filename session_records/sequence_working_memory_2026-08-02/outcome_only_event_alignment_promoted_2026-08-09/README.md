# Outcome-only event-space alignment — promoted bounded result

This two-seed audit trained a source external register and decoder, froze
them and the parent controller, cyclically permuted the learned event tensor,
and trained only a replaceable event bridge from sampled scalar verifier
outcomes. The bridge also received a zero controller-state channel, so the
result cannot be attributed to privileged parent state.

Both seeds passed every bounded gate:

- source capability mastered: `0.941` and `0.992`;
- changed representation below mastery before adaptation: `0.516` and `0.727`;
- bridge recovered target capability: `0.992` and `0.996`;
- shuffled-outcome controls stayed below mastery: `0.559` and `0.613`;
- source retention, frozen parent, external register, and decoder digests all
  passed;
- stable bridge prefixes appeared at `4,096` and `2,048` verifier bits;
- replayed examples: `0`.

This promotes one deterministic representation-alignment mechanism under a
fixed synthetic event permutation. It does not establish arbitrary modality
alignment, general continual learning, unrestricted memory growth, or
recovery from an unknown non-invertible representation change.
