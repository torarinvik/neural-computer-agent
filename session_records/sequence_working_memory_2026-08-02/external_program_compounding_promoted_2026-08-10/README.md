# External program-router compounding — promoted

This audit tests the CPU-like external program memory under a genuine
source-to-target continuation. A frozen register interpreter and frozen
cognitive controller execute opaque programs. The source external route cell
first masters two programs. A target stream reuses the same opaque event
interface and introduces a third program in a separable novelty subspace.

The target cell is selected through a copy-on-write challenger: a transferred
source state and a fresh state receive the same 64-row factual probe, and only
the winner continues. The source cell is retained as an immutable external
memory file; source rows are not replayed during target adaptation. Stable
threshold accounting requires the first measured target prefix that remains
mastered at every later measured prefix.

| seed | warm target updates | fresh target updates | target ratio | old-cell retention |
| ---: | ---: | ---: | ---: | ---: |
| 2401 | 628 | 1,000 | 1.59x | 97.67% |
| 2402 | 628 | 1,000 | 1.59x | 95.67% |
| 2403 | 628 | 1,000 | 1.59x | 98.67% |

Warm cost includes 128 challenger updates (64 per candidate) and 500
continuation updates. Fresh cost is the matched 1,000-update stable prefix.
All three seeds passed source mastery, warm/fresh target mastery, stable
positive transfer, old-cell retention, frozen controller/interpreter/program
memory, source-state copy-on-write, new-program presence, zero old-regime
replay, and shuffled-outcome rejection. The controller received zero
optimizer updates.

This promotes a bounded external program-cell compounding result: an already
mastered external route makes a later opaque program capability cheaper to
acquire while the old cell remains intact. It is not arbitrary program
induction, unrestricted memory growth, or general continual learning. The
next pressure test is learned context addressing between multiple such cells,
including overlapping rather than hand-separated novelty support.
