# Fresh-outcome neural consolidation of external files

This audit closes the gap left by logical row compaction. Two protected
external files were replaced by one routed external stack with one shared set
of weights. The inherited student started from source 0, then learned both
source procedures from fresh verifier outcomes; a fresh student received the
same mixed-task budget. The primary stable-prefix curves tied in both seeds,
so inherited weights were retained only after a separate fresh maximin
verifier showed a strict `0.02` worst-source behavior advantage.

The source procedures were:

1. `reverse -> adjacent_xor -> complement -> prefix_parity`
2. `global_parity -> reverse -> adjacent_xor -> rotate`

The target was `prefix_parity -> global_parity -> rotate -> complement`.
The controller stayed frozen, source files were not replayed as training
examples, and the shared replacement was admitted only through the protected
artifact transaction.

Both replicas passed every promotion gate: two source rows became one,
aliases resolved to the identical artifact digest, both source capabilities
remained independently protected, the shared artifact preserved both source
behaviors after reload, the target was learned and admitted by capacity growth,
the target reloaded at `1.0000`, the frozen controller digest was unchanged,
and replayed examples were zero. The replacement payload was `335,456` bytes
versus `670,912` bytes for the two source artifacts.

This promotes bounded behavior-verified neural consolidation and reusable
shared computation. It is not arbitrary program induction, unrestricted
memory growth, or general continual learning. The short rung rejected the
transaction because the source artifacts were not yet mastered; its report is
retained as `report_short_rejected.json`.
