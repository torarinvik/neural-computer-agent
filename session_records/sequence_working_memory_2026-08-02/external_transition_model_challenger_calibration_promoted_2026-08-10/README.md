# Broader disjoint transfer-challenger calibration

This three-seed promotion audits the transfer-vs-fresh decision mechanism on
seven distinct opaque transition dynamics: two source regimes followed by five
target regimes. For every target, both isolated candidates receive the same
eight-update factual probe and are then trained independently to the complete
mastery gate. The live external bank commits only the probe-selected candidate.

All 15 target comparisons selected the candidate that later required fewer
updates to full mastery. Every transfer and fresh candidate mastered, random
intention floors stayed below mastery, contexts remained separated, prior
slots were byte-stable, the controller stayed frozen, and old-regime replay was
zero.

This promotes a bounded cost-predictive transfer challenger over a broader
disjoint family. It does not establish unrestricted memory growth, arbitrary
new computation, or general continual learning. The earlier five-seed audit
with one negative-cost seed remains a required conservative control.
