# Factored factual memory under randomized partial windows

This archive promotes the first randomized-missingness pressure test for the
canonical factored router. Four opaque nonlinear regimes arrived through two
disjoint seven-row windows selected by a per-seed random permutation. The
random-feature residual learner consumed all fourteen observed rows exactly
once and used four independent rows for held-out promotion.

Across five seeds, every regime promoted, all random three-row partial reads
routed to `[0, 1, 2, 3]`, mixed-regime evidence remained ambiguous, and the
persistent sparse factual-overlap index round-tripped exactly with `56` unique
records. The controller, shared base, and context encoder stayed byte-stable;
old-regime replay and optimizer updates outside external residual statistics
were zero.

This promotes bounded randomized partial-window factual identity. It does not
establish arbitrary real multimodal missingness, learned semantic identity,
unrestricted growth, or general continual learning.
