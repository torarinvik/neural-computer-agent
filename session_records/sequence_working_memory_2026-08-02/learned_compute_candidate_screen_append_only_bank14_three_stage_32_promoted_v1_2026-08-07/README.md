# Bank-14 three-stage append boundary (2026-08-07)

This pressure test increases the opaque candidate bank from ten to fourteen
while retaining three sequential isolated append stages. Eight candidates are
mastered in the frozen base and six outcome-unseen candidates are split into
three two-candidate extensions. Later extensions activate only after the
cumulative scalar-verifier failure schedule. The controller and base screen
remain frozen and no examples are replayed.

At the 32-update experiment rung, both fresh extensions and the full
selective query-side prior pass both seeds. Fresh post-failure unseen routing
is `1.0000/0.8333`; query-prior routing is `1.0000/0.9063`. All strict gates
pass: known retention, stage-local permutation, exact reload, frozen core,
reward-shuffled null, and zero replay. The matched fresh control means this
promotes cardinality scaling of bounded three-stage append growth, not a new
causal prior-efficiency claim. The prior remains an optional memory-side
initializer whose strength and benefit depend on the boundary.
