# Goal-conditioned external lifecycle rewrite — promoted

This two-seed audit composed query-conditioned verifier-gated eviction,
held-out verified consolidation of equivalent surviving models, and verified
float16 storage compression on real affine factual transition models.

Both seeds passed every gate: query-aligned slot retention, held-out retained
behavior, stable logical IDs, bank-owned telemetry preservation, normal and
compressed checkpoint persistence, exact policy persistence, zero controller
updates, and zero replayed transition examples. Consolidation reduced the
three physical models to one shared parameter object after the disposable slot
was removed; compression selected `torch.float16`.

This promotes bounded lifecycle composition. It does not promote unrestricted
memory growth or general continual learning; verifier authority and bounded
capacity remain explicit.
