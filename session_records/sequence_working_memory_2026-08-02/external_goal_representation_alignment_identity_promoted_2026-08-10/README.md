# Learned opaque goal-alignment identity

This promoted four-seed pressure test removes the frontend ID from runtime
routing. The bank learns bounded slot-local prototypes from generic summaries
of learned frontend tensors, routes by score and margin, and refuses
ambiguous or missing signatures. Admission remains held-out-gated; identity
prototypes are written only during verified admission.

Across seeds `84801`–`84804`, runtime routing accuracy was `1.0` and the
shuffled identity control was `0.0`. Ambiguous and missing signatures were
refused in every run. A valid unseen swapped frontend was quarantined at
capacity, promoted after stable-ID eviction, and reached `0.9667`–`1.0`
mastery without a runtime frontend ID. The corrupted candidate stayed
quarantined and was never served. Persistence was exact, route reads were
non-mutating, and the controller, factual model, and verifier memory stayed
byte-stable with zero replay.

This is bounded learned signature routing, not semantic open-world identity
discovery, unrestricted memory growth, or general continual learning.
