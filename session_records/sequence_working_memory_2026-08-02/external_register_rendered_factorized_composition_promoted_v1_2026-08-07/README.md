# Promoted factorized external-register composition transfer

Date: 2026-08-07  
Status: promoted narrow result  
Schema: `neural-computer.external-register-rendered-composition-report.v1`

This milestone promotes one bounded result. A frozen parent controller emits
rendered learned events. A recurrent external context ingests each active
event, a shared factorized interpreter executes two opaque instruction vectors
on an external register, and separate output decoders remain outside the
controller. Reverse and complement are acquired separately; a fresh decoder
then learns the held-out `complement_reverse` composition.

Across seeds 69316 and 69317:

- stable composition mastery: `4,096` verifier bits on both seeds;
- matched fresh learner: `8,192` stable bits on both seeds;
- fresh-over-inherited stable-bit transfer: `2.0x` on both seeds;
- reverse retention after adding the second instruction: `0.9844` and `0.9688`;
- reward-shuffled composition: `0.4336` and `0.2891`;
- missing-evidence composition: `0.5000` on both seeds;
- exact reload and checksum-corruption rejection: passed on both seeds;
- frozen parent digest and zero replay: passed on both seeds.

The promotion boundary is deliberately narrow: learned external register
composition and positive transfer into this rendered two-instruction task.
It does not establish unrestricted memory growth, arbitrary program induction,
natural-language or speech capability, or general continual learning without
catastrophic forgetting. The next pressure test is a third instruction and a
reversal/retention run over a fresh Brain Workshop primitive family.
