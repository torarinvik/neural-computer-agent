# Append-only learned compute-candidate screen growth (2026-08-07)

This promoted experiment tests isolated external memory growth for the
learned compute-candidate screen. The four-candidate mastered base is copied
into an independently versioned base and frozen. Two outcome-unseen
candidates receive a separate extension trained on 64 fresh scalar-verifier
updates. The extension can compete only after the old route supplies a
verifier failure; fresh verifier admission remains authoritative.

Across seeds `69316` and `69317`, known-candidate novel-context routing stays
at `1.0000`. The unseen candidates route at `0.0000` before the failure gate
and `1.0000` after it. Base and extension candidate permutations, exact
reload, frozen-core, reward-shuffled null, and zero-replay controls pass.

This promotes safe append-only screen growth and isolates the prior learned
state from new-candidate calibration. It does not establish arbitrary new
computation, unrestricted memory growth, or general continual learning. Full
accounting is in `sample_efficiency_ledger.json`; report checksums are in
`SHA256SUMS`.
