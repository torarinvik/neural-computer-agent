## Claim boundary

This demonstrates calibrated replay-free growth to the fixed 20-family bank
limit. It does not establish unbounded memory growth, arbitrary program
induction, compositional execution of arbitrary new algorithms, or general
continual learning. The next meaningful test is a changing distribution with
new family statistics or a dynamically expanded bank, not simply more updates
on this closed pattern bank.
