# Verified external representation-space migration — promoted

Two seeds accepted a copy-on-write factual-bank candidate with new state and
intention space IDs after held-out stable-address verification. Both seeds
rejected an equal-width candidate whose factual transition behavior drifted,
and rejected an old planner whose representation IDs did not match the new
bank. No controller updates or replayed transition examples were used.

This promotes an explicit compatibility and migration gate, not arbitrary
representation alignment or general continual learning.
