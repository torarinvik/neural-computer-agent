# Drift-aware sparse factual identity

This archive extends the promoted nonlinear factored drift rung with the
persistent sparse factual-overlap index. A shared nonlinear base remains
frozen; a target residual version receives partial evidence and then a later
small drift through the copy-on-write bound-slot gate. The same opaque logical
slot must remain identifiable before and after the drift.

Across five seeds, source and target promotion, drift held-out quality, prior
target retention, source/target alternation, corrupted-update rejection, exact
persistence, and frozen-controller/base/context-encoder controls all passed.
Each seed retained `46` sparse factual records: 20 source, 20 target, and 6
drift rows. Contradictory outcomes for the same opaque input are preserved as
separate records rather than averaged into a fact that matches neither
version.

This promotes bounded replay-free nonlinear drift retention with conflict-
preserving sparse identity. It does not establish arbitrary nonstationarity,
learned semantic identity, unrestricted growth, or general continual learning.
