# Page-local representation growth promoted (2026-08-07)

This audit keeps the frozen bank-26 source page on a permutation-invariant
affine-normalized opaque signature and gives six append pages raw identity
views. Each raw page receives a representation-matched copy-on-write prior;
the controller and event encoder are unchanged. A local rank-margin gate
prevents incompatible page score scales from suppressing an extension after
its cumulative scalar-verifier failure gate opens.

The exact archived configuration uses 32 parent updates, 1,024 normalized
source updates, 512 raw-prior updates, 1,024 reward-shuffled null updates, and
32 fresh calibration updates per two-candidate append stage. Both seeds pass
strict per-candidate known and unseen mastery at `1.0000/1.0000`, candidate
permutation, reload, reward-shuffled null, frozen-base, frozen-core, and
zero-replay gates.

This promotes a bounded heterogeneous page representation boundary. The
representation assignment is an experimental factor, not a learned general
representation selector, and the result is not general continual learning.
The extra raw prior is an explicit source-training cost; the 512/512 split is
archived separately because it fails hard-seed known retention.
