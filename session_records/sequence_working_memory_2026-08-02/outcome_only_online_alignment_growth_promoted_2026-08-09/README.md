# Outcome-only online alignment growth — promoted bounded result

This two-seed audit first mastered and routed three external alignment cells,
then introduced an unregistered fourth dense event transform. A new bridge
cell was trained from scalar verifier outcomes, frozen, and admitted. The
protected address was an immutable opaque event-signature key appended to the
external key bank; no old stream examples were replayed during growth.

Both seeds passed:

- initial three-cell routing and action mastery;
- new unregistered cell mastery: `0.984` and `0.980`;
- new-cell shuffled controls: `0.496` and `0.449`;
- protected key routing accuracy `1.000` across all four cells;
- selected-cell action mastery across all four cells;
- key corruption detection, source retention, and frozen parent/register/
  decoder digests;
- replayed examples: `0`.

A matched shared-head expansion is retained as a negative control: it lost two
old routes in both seeds despite freezing old output rows. This demonstrates
why append-only shared classifier growth is unsafe and why immutable external
address keys are required.

This promotes bounded online admission and no-replay retention of a new
alignment cell. It does not establish unrestricted growth, eviction or
consolidation, arbitrary frontend discovery, or general continual learning.
