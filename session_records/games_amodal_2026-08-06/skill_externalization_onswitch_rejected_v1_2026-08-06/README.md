# Rejected: single-skill externalization learns an on-switch (2026-08-06)

The double dissociation itself succeeded on both seeds: fetched mastery
0.9258/0.9277 with the bank, collapse to 0.0020/0.0625 with the bank
withheld, fixed computing-parameter counts, causal nulls clean, zero
replay. But the random-artifact control failed decisively: a same-norm
random artifact restores full skill (0.9082/0.9355). With only one skill
in the system, content cannot matter - the artifact degenerated into a
presence cue and the skill remained in the weights behind that gate.

Repair (v2): random-artifact ignorance training to close the presence
shortcut, and two skills through one core so the artifact must specify
which program runs, with a cross-artifact gate.
