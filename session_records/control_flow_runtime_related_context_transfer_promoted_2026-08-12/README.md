# Gated related-context route transfer

This record promotes the canonical audit implemented in
`experiments/recipe_expressibility/control_flow_runtime_related_context_transfer.py`.

An external checksummed route table first learned a protected file for one
opaque trajectory query. A nearby but unseen query could borrow that protected
preference through an opt-in metric tolerance. Its subsequent scalar outcomes
were stored in a new independent row, allowing a local reversal without
changing the source row. Distant queries retained append-order fallback.

file order:

- matched fresh related lookup: `0.0000`;
- local related reversal: `1.0000`;
- source retention after reversal: `1.0000`;
- reward-shuffled related transfer: `0.0000`;

- replayed examples: `0`.

The learned quantity is proximity in the current opaque route-query space.
This is bounded metric-neighborhood external-memory reuse, not semantic
relatedness, robust representation migration, unrestricted growth, arbitrary
new computation, or general continual learning.
