# Sparse consequence route veto

This is a mechanistic boundary test for the external factual router. A
committed slot contains opaque input/consequence facts. A new bundle contains
one contradictory consequence whose aggregate mean error remains below the
ordinary route threshold. The sparse index vetoes the slot before ordinary
mean-error routing; unknown inputs remain eligible.

The test does not claim open-set discovery, Brain Workshop mastery, or general
continual learning. It preserves the export's “retrieve by key, then verify
the consequence” lesson as reusable memory infrastructure.
