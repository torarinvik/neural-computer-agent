# Frozen-controller external-memory audit — 2026-08-01

## Question

Can the agent acquire a context-specific behavior after its recurrent state is
erased while the controller and every adapter remain frozen?  The only mutable
state is a controller-produced key/value row in RAM and serialized disk
memory.  Empty, shuffled, and corrupted memory are causal controls.

This is deliberately the mastered binary-mapping task.  It tests episodic
memory acquisition, not discovery of a genuinely new primitive.  The latter
remains the adjacent private-relation-remapping target in Gate 1 of the
script-alignment ladder.

## Method

`audit_frozen_external_memory.py` uses the persistent-memory checkpoint
`unified_persistent_capacity40_temp50_seed4801.pt`.  For each context, a
frozen controller produces a support key and outcome-bearing value.  The row
is written to a bounded `DiskLatentMemory`, saved, reloaded, and queried after
the controller state is reset.  No optimizer or model parameter is touched.
The audit also replays the pixel-level rule reversal and checks that the
controller state digest is identical before and after the full run.

## Result

The 256-context, capacity-eight audit ran on MPS in about one second:

| condition | accuracy |
|---|---:|
| serialized disk memory | **97.66%** |
| no memory | 50.00% |
| shuffled values | 51.56% |
| corrupted values | 46.09% |
| same-context oracle value | 100.00% |

The corresponding reversal audit on the disk path reached 96.88% and a
100.00% paired prediction-flip rate.  The controller state hash was exactly
unchanged.  The complete JSON report is generated by the audit script and is
kept outside the checkpoint/weight policy.

## Interpretation

This closes the narrow claim that a frozen controller can use newly written,
serialized experience to perform a previously unseen context-specific episode
without updating its weights.  The controls show that the gain is causally
dependent on the intact memory rows rather than a fixed action shortcut.

It does **not** show that a frozen controller can invent a new abstract
relation from memory alone.  The next high-value experiment is the same audit
on the private relation-remapping task: the visual same/different primitive
is mastered, but each context privately maps the relation to normal or
reversed opaque actions.  Passing that task would close Gate 1; failure will
localize whether the missing ingredient is the key, value, or the controller's
generic read interface.
