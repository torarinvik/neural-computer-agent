# Second-generation option composition — pre-registration

The verified three-action option is retrieved as one opaque primitive. A new
binary router chooses between that primitive and the fourth-ranked physical
memory read. Flat reset must relearn all four physical actions.

Zero-training viability at capacity 6:

- old verified option utility: `0.72848`;
- four-action oracle utility: `0.92482`;
- headroom: `19.63` points;
- fourth read beats the old option in `17.16%` of contexts.

The new router sees the previous seven generic statistics plus only
third-to-fourth score margin and fourth-candidate usage. It sees randomized
attempted option and scalar outcome. No unattempted outcome, oracle action,
correct answer, task name, or semantic label enters training.

Both arms receive 960 verifier bits and 64 replay optimizer updates. Pass:

1. composition reaches old-option+2 points;
2. it reaches the target before flat four-action reset;
3. it remains above target at the final checkpoint;
4. oracle remains at least 2 points beyond the target.

A pass earns one identical fresh-seed replication, then independent confirmation
and causal/retention/persistence audits.

Seed 8061 passed:

- composition reached target at 960 verifier bits;
- flat four-action reset did not reach target;
- inherited option utility: `0.71669`;
- composed final utility: `0.74684`;
- flat final utility: `0.71956`;
- each arm used 64 replay updates and about 0.30 seconds.

Fresh seed 8062 must pass the identical gate before any audit or scaling.

Seed 8062 passed at 720 bits while flat reset again failed by 960. Its frozen
candidate then passed independent confirmation (`+3.17`-point lower 95% bound),
improved all eight streams, passed reversal and retention, but failed the
pre-registered new-feature causality gate: shuffling only the two added
statistics cost 0.63 points, not 2. The candidate was not stored.

The result shows those new values are redundant. The next tiny fork removes
them from both learners: the second-generation router and flat reset receive
only the inherited seven-feature representation. If training passes, its audit
will shuffle all seven router inputs while keeping the previous option's own
inputs intact. This directly tests reuse of the inherited representation.

Seed 8064 passed with inherited features only: composition reached at 960 bits,
flat reset did not, and final utility improved from `0.70351` to `0.75601`.
Fresh seed 8065 must pass identically before the revised causal audit.

Seed 8065 passed at 480 bits versus flat reset at 960. The revised frozen audit
passed confirmation, every-stream improvement, router-feature shuffle,
reversal, and four-rule retention. Binary retention missed only the
`zero_shot_near_chance` cutoff: `60.16%` against `60.00%` at n=128, while
post-feedback and reversed performance were both 100%. The immutable controller
cannot have been modified by the router. Retention is rerun at n=512 to resolve
this one-sample boundary result; thresholds remain unchanged.

## Verified second-generation breakthrough

The n=512 retention rerun passed every gate.

### Frozen audit

On 2,400 new randomized attempted options:

- estimated improvement: `+5.89` points;
- lower 95% confidence bound: `+4.02` points.

Across eight additional streams:

The new composition improved every stream. Shuffling all seven inputs seen by
the router—while leaving the old option's inputs intact—cost 9.84 points.
Reversing only the new router cost 26.29 points. Binary mapping and four-rule
retention passed at n=512.
