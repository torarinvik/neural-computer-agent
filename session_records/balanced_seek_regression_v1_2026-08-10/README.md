# Balanced-seek regression (F123)

Probe 223, 3 seeds. Targeting both object planes equally during
collection annihilates reading: entry effect +0.24..+0.30 (F118) ->
+0.0001..+0.0005; held-out +0.08..+0.11 -> -0.045..-0.048 (floor).
Polarity scalars stop sign-splitting.

Mechanism: plane-1-only seeking made the twins marginally asymmetric
(normal mostly-positive, inverted mostly-negative), so reading paid.
Balanced seeking equalises the marginals, the twin-average becomes a
good fit, and the model settles there — F106 re-created from the data
side, where the ignorance term has no purchase.

Lesson: asymmetry in the DATA is what makes reading pay.
