# Factorized control-flow loop growth promotion

This archive records the four-seed audit for external structural proposal
credit. The frontier now learns aggregate scalar quality over three generic
edit factors: mutation operator, position relative to the non-terminal
boundary, and opaque instruction identity. The policy is external state; the
controller is absent/frozen and no verifier rows are retained.

Command:

```text
.venv/bin/python experiments/recipe_expressibility/control_flow_factorized_loop_growth.py \
  --seeds 17 18 19 20 \
  --report-out session_records/control_flow_factorized_loop_growth_promoted_2026-08-12/report.json
```

Results:

- all 8 warm arms (four seeds, forward/reversed outcome order) discovered
  non-commuting loop lengths 5, 6, and 7;
- held-out accuracy and retention were `1.0000` at every rung;
- the matched fresh controls also found every rung;
- later-rung warm/fresh proposal ratios ranged from `0.0024` to `0.4444`,
  with mean `0.1056`;
- shuffled-feedback controls promoted zero rungs;
- policy, frontier, executable-memory reload, missing-evidence, and checksum
  gates passed;
- accounting was `23,335` unique verifier bits and `4,667` logical lifetimes,
  with zero replay and zero optimizer updates.

This promotes bounded replay-free factorized structural-credit transfer across
longer external loop programs. It does not establish efficient arbitrary
program synthesis, unrestricted memory growth, arbitrary semantic learning, or
general continual learning.
