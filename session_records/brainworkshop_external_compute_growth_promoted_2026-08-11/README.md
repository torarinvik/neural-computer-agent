# Promoted external compute-file growth

This record promotes the two-seed rendered Brain Workshop rung from
`experiments/brainworkshop_canonical/external_compute_growth.py`.

The controller and event frontend are frozen. `symbol_parity` is learned into
an opaque external file first. A fresh append-only event-window compute basis,
opaque instruction, adapter, and keypress decoder then learn `triplet_parity`
from scalar verifier outcomes with no replay of the source task. The target
file is selected explicitly so this record measures computation acquisition,
not route discovery.

Both seeds pass source mastery, target mastery, exact source retention, source
file immutability, frozen-core digests, history dependence, and zero replay.
The target reaches `0.8736` and `1.0000` mean stable retention accuracy on
seeds `17` and `18`; resetting the external history returns both controls to
chance. The fresh-file comparator is reported in each JSON record and is not
treated as a promotion gate.

This is a promoted isolated external-computation blueprint, not a claim of
arbitrary program induction, unrestricted memory growth, route discovery, or
general continual learning.
