# Live held-out context-generalization promotion

This record closes a concrete routing bug and promotes its causal test. The
memory-side route ledger was calibrated on two exact learned cue embeddings for
already verified delay-1 and delay-2 executive artifacts. After a checksummed
`AgentBrain.bank` reload, six previously unseen context keys were generated by
small opaque perturbations of those learned event tensors. None existed in the
route table before selection.

The live router used the nearest protected context through
`behavior_probabilities()` rather than treating every held-out key as an
unknown append-order route. It selected slots `0,1,0,1,0,1` for alternating
1-back/2-back episodes and scored `1.0000` on all 51 held-out eligible verifier
bits. Each variant was then stored as its own route row; source contexts were
not overwritten. The bank digest matched across reload before and after the
variant episodes. Training used 136 bits across 16 lifetimes; total route
updates were 22. Controller, decoder, and executive-program updates were zero,
and replay was zero.

This promotes bounded learned-event context generalization, not arbitrary
semantic extrapolation. The variants remain within the configured opaque
generalization radius, and the skills themselves were pre-verified.

Reproduce with:

```bash
PYTHONPATH=src .venv/bin/python \
  -m experiments.brainworkshop_canonical.live_executive_route_generalization \
  --report-out /tmp/live-executive-route-generalization.json
```
