# Context-window gain screen

The harder rendered n-back-5 target was screened with the validated masked
context summary and tight route tolerance (`0.01`). Active and passive arms
received matched exposure and unchanged promotion/retention gates.

Across eight seeds, gain `0.05` completed `5/8` active and `4/8` passive runs;
gain `0.15` completed `4/8` active and `4/8` passive; gain `0.30` completed
`2/8` active and `1/8` passive. The higher gains are therefore rejected for
this boundary. Gain `0.05` remains an explicit promoted experiment setting,
not the global default, because changing the default regressed a historical
no-goal compatibility route.
