# Outcome-only counterfactual query-address growth

This promoted bounded rung trains eight fresh external temporal candidate files
at opaque offsets `1..8` using paired common-random action arms and scalar
keypress outcomes. A stable held-out gate admits exactly offset `4`. The
admitted capability file is then frozen while a context-keyed external route
ledger evaluates all eight target offsets with fresh paired scalar probes and
protects offset `5`.

Seeds `17`, `18`, and `19` pass every gate: unique candidate admission,
source and target mastery, target offset selection, source retention, wrong
offset and missing-history rejection, unknown-query rejection, shuffled
feedback rejection, exact route reload, frozen controller/event encoder/file,
counterfactual-credit accounting, and zero replay. Source and target retained
accuracy are `1.0000` on every seed.

Per seed, the accounting is `165,632` unique verifier bits, `336,896`
counterfactual-arm bits, `16,704` unique logical lifetimes, `33,792`
counterfactual logical lifetimes, `1,024` optimizer updates, `72` promoted
route-memory updates, and zero replay. The raw reports are `seed-17.json`,
`seed-18.json`, and `seed-19.json`.

The claim is deliberately bounded: replay-free growth of an isolated external
address route under a frozen controller and frozen promoted readout. It is not
general continual learning, unrestricted memory growth, arbitrary new
computation, or program induction.
