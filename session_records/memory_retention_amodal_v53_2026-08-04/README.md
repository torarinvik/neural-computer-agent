# Mixed fixed-write acquisition and rehearsal rejection

v53 uses the fixed-write coupled-action protocol only during initial parent
acquisition, then returns to ordinary outcome-only parent rehearsal during
retention. The main seed reaches stable threshold and preserves mastered
primitive retention at 1.000, but corrupt-memory recall rises to 0.519,
breaking the causal gap gate. The transferred parent remains unqualified and
the fresh-control transfer status is not promotable.

This narrows the phase-transition issue but does not solve it. The original
policy-gradient protocol remains the default.
