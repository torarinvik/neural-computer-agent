# Promotion prediction-tolerance screen

The hard rendered n-back-5 target was screened with tight routing (`0.01`),
masked context gain `0.05`, and matched active/passive exposure. The one-step
held-out model-family prediction tolerance was `0.05`, `0.10`, or `0.15`; the
recursive held-out and source-retention gates were unchanged.

All three tolerances produced `5/8` active and `4/8` passive complete runs on
the same eight seeds. The wider threshold therefore did not recover the
current failure modes and was rejected as a new branch.
