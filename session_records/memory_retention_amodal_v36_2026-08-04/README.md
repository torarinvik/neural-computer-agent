# Parent-protection control rejection

This control froze the mastered parent after qualification and trained only the
generic memory write-policy head. It still learned a position shortcut:
target-last recall was `0.764`, while target-first was `0.506`; intact recall
was `0.646`. Parent protection therefore does not recover cue-conditioned
utility. The remaining failure is write credit assignment itself, not
destructive co-adaptation of the parent.
