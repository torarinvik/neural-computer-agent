# Active discovery probe — matched exposure promotion

The online external-memory discovery audit now has a caller-owned active
evidence mode. Once a provisional target file is staged, the system builds an
isolated source/candidate model view, selects an opaque intention by predicted
model disagreement, executes it through the ordinary frozen controller and
keypress decoder, and routes the observed successor back into the provisional
file. Promotion gates are unchanged. A passive arm receives the same extra
rendered lifetime and rows but keeps the ordinary candidate-intention pool.

Across two independent 24-seed blocks (`80–127`), active discovery passed
`33/48` complete gates versus `28/48` for the matched passive exposure arm.
The paired outcomes were six active wins and one active loss. Both arms kept
the source slot byte-stable in `48/48` runs; both left the controller
unchanged, replayed zero examples, and consumed the same `1,440` transition
rows. Active selection used `288` additional probe rows and `1,533` unique
verifier bits; the passive arm used `1,512` bits.

This promotes a narrow causal active-evidence acquisition seam. It does not
promote n-back mastery, arbitrary computation, unrestricted memory growth,
universal positive transfer, or general continual learning. The gain is still
seed-sensitive and costs an additional lifetime; the next rung must test
whether the active probe transfers across genuinely new regimes and whether
its evidence budget improves stable bits-to-threshold.
