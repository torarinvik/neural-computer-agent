# Recipe basis atomic-gap instrument

This is an architectural instrument inspired by the exported games session.
The export's quantitative basis result remains **SINGLE-SOURCE,
UNREPLICATED**. This repository reran only the finite symbolic expressibility
check, not the export's learned-interpreter numbers.

`RecipeBasis` represents the current generic atomic vocabulary and an optional
domain-neutral `parallel` combinator. The earlier six-slot/eight-value check
was a uniform-domain atomicity probe, not a two-valued toggle result.

The result is a mechanism check, not a capability promotion. On a two-valued
subdomain, the existing explicit-modulus sequence `INC 0; INC 1` expresses a
toggle. `PARALLEL` only represents the stricter requirement that both effects
commit in one atomic verifier step.
