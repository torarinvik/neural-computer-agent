# Recipe basis atomic-gap instrument

This is an architectural instrument inspired by the exported games session.
The export's quantitative basis result remains **SINGLE-SOURCE,
UNREPLICATED**. This repository reran only the finite symbolic expressibility
check, not the export's learned-interpreter numbers.

`RecipeBasis` represents the current generic atomic vocabulary and an optional
domain-neutral `parallel` combinator. On six slots and eight values:

| basis | candidates | paired increment target |
| --- | ---: | --- |
| atomic only | 118 | certified inexpressible |
| atomic + parallel | 5,518 | expressible; found after 119 checks |

The result is a mechanism check, not a capability promotion. The paired
increment target is the generic representative; on a two-valued subdomain it
is the simultaneous pair-flip case.

The required next rung is a two-seed learned-interpreter audit with random
program pretraining, matched baseline/extension curves, search-cost
accounting, and fail-closed reachability controls.
