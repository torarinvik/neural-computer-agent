# Executive compositional transfer promotion

This record promotes a bounded structural-transfer result for the external
executive. A source program first verifies a generic equality relation at a
one-tick temporal displacement. On a held-out 2-back verifier, the warm learner
retains that relation fragment and autonomously searches only four opaque
relative-delay bindings. The matched fresh learner searches the Cartesian
product of the same four delays and four generic relation fragments.

Candidate ordering is a deterministic hash of seed and opaque artifact digest.
The search receives only attempted scalar lifetime accuracy. The n-back depth,
correct action, symbol identity, and unattempted-candidate outcomes remain
verifier-private. The encoder, executive operators, and intention decoder are
frozen; optimizer updates and replay are zero.

Across two disjoint 16-seed blocks, both arms admitted the identical correct
artifact on every seed. Warm search required 30,208 unique target verifier bits
and fresh search required 84,992, for a combined fresh/warm transfer ratio of
2.8136. Warm search was strictly faster on all 32 seeds. The source primitive
retained perfect behavior after target search. Irrelevant inheritance,
destroyed reward, shuffled actions, and missing history admitted no artifact.

Both seed blocks now also admit the source and target into checksummed
heterogeneous `AgentBrain.bank` files. Each artifact contains its instruction
stream and a safe allow-listed operator manifest. Reload reconstructs fresh
production operators, preserves both artifact and bank digests, and scores 1.0
on source and target behavior. The canonical container can also preserve a
legacy temporal-address family; importing an old torch bank is explicit and
validated rather than implicit.

The same run freshly verifies a generic receive-only fragment, composes it with the
verified 1-back temporal loop, records both parent slots and content digests,
and reloads the composed child at 1.0 source mastery. The child is admitted by
the same stable-prefix verifier gate after fresh behavioral rollouts. This
qualifies durable, behavior-preserving composition mechanics; it does not claim
that this receive-only prelude adds a new capability.

Parent selection is now itself memory-side and opaque. The deterministic search
enumerates ordered parent pairs by slot-independent content-addressed priority,
executes a fresh screening rollout, and runs fresh confirmation only for a
promising candidate. In both promoted blocks the wrong first candidate used one
stage and the admitted child used two, reducing composition-search experience
from 2,304 to 1,728 combined verifier bits. Non-final parents without a
reachable terminal handoff are excluded so a persistent loop cannot make later
components dead code. The reports record attempted pairs, evaluation stages,
unique verifier bits, logical lifetimes, replay, and the exact bank digest
before and after search. Reload also recomposes the recorded parents and binds
the resulting digest to the child and admission.

An isolated batch-32 interpreter benchmark alternated the pre-cache commit and
the optimized tree over two 3,000-tick measurements each. Mean runtime fell
from 3.299 seconds to 2.755 seconds, a 16.5% reduction. This measures immutable
metadata caching only; the separate staged-verifier result measures experience
efficiency.

This proves bounded reusable program structure, smallest-failed-binding search,
and durable restart-safe heterogeneous execution. It does not yet prove
controller-generated candidate libraries, unbounded instruction induction, or
physical Brain Workshop transfer.
