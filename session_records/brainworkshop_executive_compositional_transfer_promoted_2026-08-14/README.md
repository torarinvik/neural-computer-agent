# Executive compositional transfer promotion

This record promotes a bounded structural-transfer result for the external
executive. A source program first verifies a generic equality relation at a
one-tick temporal displacement. On a held-out 2-back verifier, the warm learner
retains that relation fragment and autonomously searches only four opaque
relative-delay bindings. The matched fresh learner searches the Cartesian
product of the same four delays and four generic relation fragments.

Candidate ordering is a deterministic hash of seed and opaque artifact digest.
The search receives only attempted scalar lifetime accuracy. The n-back depth,
correct action, symbol identity, and unattempted-candidate outcomes remain
verifier-private. The encoder, executive operators, and intention decoder are
frozen; optimizer updates and replay are zero.

Across two disjoint 16-seed blocks, both arms admitted the identical correct
artifact on every seed. Warm search required 30,208 unique target verifier bits
and fresh search required 84,992, for a combined fresh/warm transfer ratio of
2.8136. Warm search was strictly faster on all 32 seeds. The source primitive
retained perfect behavior after target search. Irrelevant inheritance,
destroyed reward, shuffled actions, and missing history admitted no artifact.

Both seed blocks now also admit the source and target into checksummed `.bank`
files. Each artifact contains its instruction stream and a safe allow-listed
operator manifest. Reload reconstructs fresh production operators, preserves
both artifact and bank digests, and scores 1.0 on source and target behavior.

This proves bounded reusable program structure, smallest-failed-binding search,
and durable restart-safe execution. It does not yet prove controller-generated
candidate libraries, unbounded instruction induction, physical Brain Workshop
transfer, or migration of legacy temporal-address banks into one heterogeneous
container.
