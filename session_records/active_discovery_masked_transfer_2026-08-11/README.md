# Masked active discovery transfer — harder target regime

The active-evidence route was tested on rendered n-back-5 with opaque cue
symbol 6 using the existing `masked_mean_and_max_v1` transition context
summary. Passive matched exposure received the same extra lifetime and probe
budget; only active selected its intention by isolated model disagreement.

Across seeds `80–103`, active discovery passed `11/24` complete target gates
versus `7/24` for passive. The paired outcomes were five active wins, one
active loss, and eighteen ties. Both arms retained the source slot in `24/24`
runs, left the controller unchanged, replayed zero examples, and consumed
`678` transition rows once and `102` probe rows. Active used `416` unique
verifier bits; passive used `405`.

This promotes the masked context summary as a targeted evidence-routing option
for this harder regime. It does not promote a universal default, unrestricted
memory growth, arbitrary computation, or general continual learning. Candidate
staging is still the dominant failure class, so the next experiment should
improve pre-admission evidence and credit assignment.
