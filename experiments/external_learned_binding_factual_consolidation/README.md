# Learned binding with verified factual consolidation

This pressure test extends external memory growth with retention-safe
compaction. Three anonymous streams are grown into the shared factual bank:
two have equivalent transition functions but different opaque identities, and
one has a nonlinear transition function. The consolidation transaction must
share only the equivalent physical model parameters while retaining every
stream key, factual slot address, and routing state.

The audit includes a distinct-function rejection, a mutating-retention-probe
rejection, held-out equivalence verification, exact persistence, zero replay,
and zero controller/factual optimizer updates. It promotes parameter sharing
as a memory-side compression operation, not semantic stream merging.

This does not establish learned consolidation policy, unrestricted memory
growth, arbitrary new computation, or general continual learning.
