# Parent-conditioned executable artifact bank

This is the next boundary after replicated parent-conditioned transfer. Three
new working-memory procedures—reverse, forward, and complement—are acquired in
isolated recurrent memory-side programs over one frozen parent, persisted as
opaque artifacts, and routed through one memory bank. The bank and router
never interpret task labels or protocol fields. Promotion requires stable
prefix mastery, route permutation invariance, balanced reward-shuffled route
failure, causal wrong-artifact behavior, parent retention, reload equivalence,
checksum rejection, and zero replay.

The route learner uses pairwise target-versus-competitor credit sampled across
all rows. This avoids the cyclic fixed-pair bias that appears when a bank grows
beyond two candidates.
