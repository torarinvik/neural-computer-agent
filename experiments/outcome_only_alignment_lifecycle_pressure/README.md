# Outcome-only alignment lifecycle pressure

This audit fills an external alignment bank, protects mastered cells, exposes
one cell to a changed event space until scalar reversal evidence releases it,
then evicts only that stale cell and admits a replacement under the same
logical slot. Protected cells and the frozen controller are retained.

```text
PYTHONPATH=. .venv/bin/python -m experiments.outcome_only_alignment_lifecycle_pressure.train \
  --seed 69316 \
  --report-out /tmp/alignment-lifecycle-pressure.json
```

The result is bounded lifecycle evidence, not unrestricted memory growth or
general continual learning.
