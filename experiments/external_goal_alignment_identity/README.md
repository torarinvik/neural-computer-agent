# Learned opaque goal-alignment identity

This pressure test removes the frontend ID from runtime routing. The external
alignment bank learns bounded slot-local prototypes from generic summaries of
frontend event tensors. Runtime queries select an opaque slot by score and
margin; ambiguous or missing signatures are refused. Admission still uses
held-out alignment evidence, and identity prototypes are only written during
verified admission or an explicit verifier-approved update.

The test intentionally admits nonlinear memory before affine memory, shuffles
the identity control, quarantines a valid third frontend at capacity, rejects a
corrupted candidate, evicts by stable logical ID, and then routes the promoted
frontend without a frontend ID. It remains bounded identity evidence, not
semantic open-world identity discovery.

Run with:

```bash
PYTHONPATH=. .venv/bin/python experiments/external_goal_alignment_identity/train.py \
  --seed 84801 \
  --report-out /tmp/external-goal-alignment-identity-84801.json
```
