# Goal-conditioned external relevance under matched telemetry

This audit repeats the matched-telemetry ambiguity control, but supplies a
learned opaque query aligned with the capability needed by the current goal.
The external lifecycle combines that query/key similarity with generic
lifetime telemetry before proposing a stable logical eviction address.

The factual transition models remain real and retained behavior is checked by
held-out probes. The controller itself is not updated in this mechanism test;
the query represents the controller’s replaceable learned latent output. The
separate controller relevance experiments are responsible for learning such
cross-token representations. This experiment verifies that the external
memory boundary can use them without adding a protocol-specific reasoning
branch.

Both seeds reached `1.000` held-out selection versus the matched-telemetry
random reference of `0.500`. Evidence is archived under
`session_records/sequence_working_memory_2026-08-02/external_transition_goal_conditioned_relevance_promoted_2026-08-09/`.
