# Outcome-only contextual contradiction arbitration

This rung tests a single controller on two contradictory candidate events and
a separate context event.  The hidden rule is stable but private: context 0
selects candidate B, while context 1 selects candidate C.  The learner sees
only standardized frozen frontend events and scalar verifier outcomes; it
does not receive the rule, target, or candidate labels.

Promotion requires both hidden contexts, source-order invariance, and collapse
when the context-to-candidate assignment is shuffled or the context is
inverted.  This is a bounded arbitration result, not a claim of natural
multimodal grounding or arbitrary temporal source-reliability updates.
