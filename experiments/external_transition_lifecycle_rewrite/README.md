# Goal-conditioned external lifecycle rewrite

This audit composes three external-memory transactions on real affine factual
models: query-conditioned verifier-gated eviction, held-out verified
consolidation of equivalent survivors, and held-out verified storage
compression. Stable logical slot IDs and bank-owned lifetime telemetry are
checked across every rewrite and checkpoint boundary.

The controller is frozen and never constructed. The verifier remains the only
authority that can commit a rewrite; no transition rows are replayed. This is
a lifecycle-integrity promotion, not a claim of unrestricted memory growth or
general continual learning.

Both seeds passed the composed eviction, consolidation, compression,
stable-address, telemetry, and checkpoint gates. Evidence is archived under
`session_records/sequence_working_memory_2026-08-02/external_transition_lifecycle_rewrite_promoted_2026-08-09/`.
