# Learned binding and factual-memory growth

This pressure test advances the replacement-only lifecycle to genuine
copy-on-write growth. A learned anonymous binding proposal identifies
provisional evidence worth verifying; the external transaction grows both
live-stream capacity and factual-bank capacity, selects between replay-free
affine and random-feature factual candidates, checks an independent held-out
transition, and commits only when all prior tracks and factual slots remain
unchanged.

The audit uses delayed interleaved open-set arrivals, two sequential growth
transactions, a fresh-policy control, a verifier-shuffled policy control,
matched source retention, model-family reporting, exact persistence, and frozen
controller/encoder checks. Existing evidence is consumed once through
sufficient-statistics models; the controller and factual models receive zero
optimizer updates during deployment.

This promotes bounded external memory growth with learned anonymous proposal
selection. It does not establish unrestricted memory growth, learned verifier
design, arbitrary new computation, or general continual learning.
