# Matched-telemetry future-relevance ambiguity control

This is a deliberately negative control. Four real factual transition models
receive matched bank-owned usage, age, and prediction-error telemetry. Two
candidate models are otherwise indistinguishable; a hidden future schedule
randomly determines which one must be retained. The lifetime policy receives
only the current bank state and one verifier bit after its proposal.

The expected ceiling is random choice. If the policy exceeds it, the fixture
is leaking a signal; if it does not, the result identifies the missing
capability honestly: memory lifetime cannot infer future task relevance from
generic telemetry alone. The next architecture step must add a learned,
goal-conditioned query/relevance path while keeping the controller and memory
interfaces independently replaceable.
